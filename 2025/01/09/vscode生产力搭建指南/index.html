    搭建STM32环境(Keil Studio)注意事项

    详细教程可见 此处

    • vcpkg是一个c/c++包管理工具,需要git下来编译安装,然后配置PATH。
    • 在此环境搭建过程中vcpkg下载管理如下包。
    • vcpkg下载默认在C:\Users\Zhong\.vcpkg\,使用软连接法mklink /D "C:\Users\zhong\.vcpkg" "D:\vcpkg\vcpkgconfig"。
    • CMSIS插件环境需要一系列的pack,在PATH中添加CMSIS_PACK_ROOT,D:\Keil5\Arm\Packs,来指定包路径。更改完成后可通过cpackget --help命令查看是否更改成功,如下图。

    其他相关环境配置

    以下工具全都使用msys2管理：

    • C/C++相关工具，gnu，gdb，clang，ninja，cmake,llvm。
    • git
    • python

    使用时配置环境变量D:\msys64\mingw64\bin和D:\msys64\usr\bin。
